# dsh-kit

面向 DeepSeek Harness (dsh) 的**页面能力套件插件**：给 DSH 的浏览器界面加装可选能力，每个能力独立、互不依赖；全部关闭时 DSH 保持原版。工作台住在官方右侧边栏（一个内容一张 dock 签）。

## 功能

- **文件树**：左栏文件树，新建 / 重命名 / 移动 / 导入 / 回收站删除；点文件走官方预览。
- **对话小窗**：屏幕边缘常驻一枚把手，点开一扇浮窗对话——独立会话，可与主面互换；Ctrl+Alt+; 开合。
- **知识库 · 日程**：md 笔记库的编辑面（斜杠菜单、双链与反链、大纲、全文搜索、题目与学习复习），日程周网格 + 待办 + 计时，面板直接可写。
- **终端**：多标签终端，绑会话工作区；引擎是官方 webTerminals。
- **内置浏览器**：agent 经 `browser_*` 工具驱动系统 Edge，面板看实时画面并可直接接管；对话里的链接可改投这里。
- **手机访问**：扫码用手机连本机 dsh——令牌网关，局域网与远程双通道。
- **用量与监视**：余额 / 配额芯片，回合收尾、上下文压缩完成与 agent 提问的桌面通知。
- **网页搜索**：免 key 多源搜索替换官方付费搜索。

## 使用

- 每个组件行一枚开关（侧栏「插件」页）：关行 = 该能力整体退场（宿主端点 404、界面入口消失）。
- 需要调参数的行带自己的「配置」页；保存即写入 profile 并热生效。
- 文件树 / 知识库 · 日程 / 终端 / 对话小窗的快捷键注册在宿主「快捷键」页（Ctrl+/）。
- 运行数据在 `<DSH_HOME>/dsh-kit/`：知识库默认根、日程、内置浏览器 profile 等；知识库根目录可在行配置页里改。

## 环境要求

- dsh ≥ 0.2.0-rc.2（桌面版同版本可用）
- Node.js ≥ 22（dsh 自身要求）

## 工作原理

- 单包 + `cordis.patch.yml` 的组件行（行 name 走 exports 子路径），宿主按行加载；行关则宿主端点不物化、client 半边不注册。
- 宿主半边是 `src/*.ts`（tsc 出 `dist/`），浏览器半边是手写 `client/bundle.js`（零构建）；xterm / TipTap / pdf.js / KaTeX / mermaid / 二维码等按需从 `/dsh-kit/vendor/*` 加载。
